F26 adds options to kin ask and conversation digests; every one is off by default, so kin ask answers LoCoMo and LongMemEval-S as F25 did (rerun on F26: 95.13 and 97.80) and BEAM-1M as F25 did (80.69 on all 700 questions). On BEAM by history size, default kin ask scores 79.11 at 100K, 74.76 at 500K and 80.69 at 1M. Every kin ask score in this summary and the charts below answers from memory alone: no dataset annotations in the prompt, and no reading of the memory as of a turn the dataset cites.

Annotation-assisted runs (not memory results)

past.dev and Exabase publish BEAM scores whose answer prompt is built from the dataset's own per-question annotations: the topics to order, the rubric points the grader checks a summary against, the preference or instruction under test, and why a question may be unanswerable. Those annotations are the test set's grading material, so a score that reads them does not measure memory and is not comparable to the kin ask results above.

During this work kin ask was also run that way, with caller-hint code that is not part of this release: each question's annotations and Exabase's per-category guidance were passed as the answer instructions, the topics to order as extra searches, and knowledge-update questions were read as of the update turn the dataset cites; answers came from gpt-5.6-luna at reasoning effort none and were scored with past.dev's judge. The figures are recorded for reference only.

Notes

  • Judges follow each benchmark's target protocol: LoCoMo, Mem0's accuracy prompt on gpt-4o-mini; LongMemEval-S, the unified judge on Gemini 3 Flash; BEAM, the nugget rubric on Gemini 3 Flash. The annotation-assisted BEAM figures in the previous section use past.dev's judge: Exabase's rubric prompts on gpt-5.6-luna, reasoning off, items scored 0 / 0.5 / 1, event ordering by Kendall tau-b.
  • Turn-level claims and the new evidence options are off by default. With claims in place of facts, default kin ask scored lower on LoCoMo (93.44), LongMemEval-S (96.40) and BEAM-1M (79.56); the BEAM 1M and 10M claim stores were built with the research version of the claims prompt, which conversations.claims generalises to named speakers.
  • Token and category figures are F25's; F26 leaves the default settings unchanged.
  • Answer-key errors: 29 of F25's 73 seed-0 LoCoMo losses (about 34 of 83 averaged over three seeds) are on questions the public LoCoMo audit marks wrong.
  • Published scores are self-reported and use different answer models, judges and prompts. Sources: Exabase (BEAM), Exabase (LongMemEval), Hindsight (BEAM), Hindsight (LoCoMo, LongMemEval), Mem0, Mem0 (BEAM), Supermemory, past.dev.
