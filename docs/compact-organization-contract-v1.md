# Additive compact evidence organization v7

Internal opt-in repair, reversible source copy only. No live stores, migration, default change, provider call, historical instruction execution or changes to v6 artifacts. Prior failed evaluator protocol and all outcomes remain failed and immutable. This contract fixes mechanics; it does not freeze reader efficacy assessment.

## Pure production module

New `kindex.evidence_organizer` exports `organize(request)`, `decode(model_text)`, `OrganizerError(ValueError)` with safe code. Stdlib only, no I/O, environment, clock or network. Primitive JSON strict types; reject unknown fields, duplicate IDs, bool-as-int, invalid Unicode/nonfinite values, malformed refs. Input is copied, never mutated; output must not alias input.

Request exactly `{query,records,protected_ids,budget_bytes,order}`. Query nonblank <=4096 UTF8 bytes. Budget integer 0..16384. Order `native` or `relevance`. Records <=32, each exactly v6 organizer record schema `{id,source,kind,text,roles,links}`: nonempty id<=128bytes unique; kind fact/principle/episode/association; nonempty text<=65536bytes; source `{node_id,source_sha256,start_byte,end_byte,valid_from,valid_until}` with node_id<=256bytes, lowercase64hex SHA, integer interval. V7 supports whole source only: start=0,end=UTF8text length, SHA=SHA256(text). Times null or exact UTC `YYYY-MM-DDTHH:MM:SS[.ffffff]Z` (optional 1..6 fractional digits preserved without truncation), start<end when both nonnull. Roles exactly actor/scope/conditions/exceptions/event_time/report_time, each <=16 nonempty literal substrings <=65536bytes. Links <=16 unique `{to,relation}` to existing IDs, relation associated_with/contradicts/supersedes/depends_on. Protected IDs unique existing records, in input order. Pure host caller must already admit scope/time/trust; wrapper below supplies that boundary.

No deduplication: source identity and source versions stay distinct even with identical text. No text rewriting, truncation, new edges, semantic extraction, truth selection, or model proposal.

## Compact reversible payload

Canonical JSON (UTF8, ensure_ascii=False, sorted keys, separators comma/colon), with version2 format `kindex.evidence-organizer`. Payload contains warning, query, explicit schema/legend, records. Use a single field legend and positional arrays to avoid repeating per-record field names. Full source text occurs exactly once per included record. Replace role strings with byte ranges: each string maps to its first literal occurrence's UTF8 half-open range; decoder reconstructs the original role string, preserving order and duplicates. Retain full source IDs, SHA, time bounds, kind and directed links. Category is derived from kind only (direct_answer/applicable_principle/related_episode/speculative_association); relevance label is never authority. Literal warning must explicitly say exact match and declared graph links do not establish authority or resolve conflicts. Source metadata must be in the delivered payload, not merely an external receipt. Decoder returns `{query,records}` equal to original selected records/query; reject malformed payloads, noncanonical JSON, unknown schema/version/fields, invalid byte boundaries/hash/roles/links. A link may target an omitted record, so decoder validates link syntax but cannot require all endpoints present. No caller-controlled schema interpretation.

## Atomic correction components and budget

Build undirected connected components for packing from admitted records' stored `supersedes` AND `contradicts` edges. This is co-delivery membership only: retain original directed links, never infer inverse or transitive semantic edges. Include inbound corrections, chains, forks and cycles. No group expansion outside given pool. All members included whole or all omitted, including unprotected components. An exact match protects the entire component, never the older record alone. Association/dependency edges do not create correction components or authority.

Protected components first, ordered by earliest protected input member. Other components: native order=min input position; relevance=min member tuple (kind category order fact,principle,episode,association; negative unique casefolded Unicode word overlap query/text using r'[^\W_]+'; input position). Members within each component retain input order. Greedy skip/backfill atomic components under complete rendered UTF8 budget, including schema/warning/query/metadata. Protected component overflow omits its entire component and marks failure explicitly, not stale-only fallback. If empty envelope over budget, model_text empty and envelope_budget. No inferred winner or applicability.

Output includes exact format/version, order, model_text, utf8_bytes,text_sha256,included_ids; components with original member IDs/protected boolean/included boolean; omissions per omitted ID reason component_budget|protected_component_budget plus envelope_budget when relevant; unexpanded_links for delivered source links to omitted IDs; protected_complete boolean; per-payload body_bytes and overhead_bytes summing exactly to utf8_bytes (empty text both0). No diagnostics count as delivered evidence. Include immutable source records/hash refs in payload; emit omission details out-of-band without falsely claiming reader saw them.

## Native read-only integration

Add `practical_memory.organize(store,request)` and CLI `kin practical-memory organize --request-json ABS_FILE --json`. Existing prepare,persist,index,audit,ack unchanged. New request exactly `{scope,evaluation_time,query,top_k,protected_node_ids,total_max_bytes,order}`. Same scope, canonical instant, native read-only snapshot and egress/privacy handling as v6; top_k integer1..32; protected IDs<=32 unique nonempty<=128bytes, only accepted if exact escaped ID appears in query with Unicode word boundaries `(?<!\w)ID(?!\w)`. Nonmatching requested ID rejects invalid_request. Protection never directly fetches/refills/changes pool; report protected IDs absent after admission as unavailable.

Use one existing native hybrid_search call at explicit time with ensemble ranking,vectorsFalse,trusted_onlyTrue,expand_graphTrue,graph_hops1,include_expiredFalse,include_archivedFalse. Recheck `_admit` exact scope/client/time/trust for each unique hit; no foreign source leakage or broader admission. Do not call prepare or prepack. Whole admitted sources only; sources over65536bytes or empty omitted with explicit reason. Before formatting omissions, compute correction/contradiction components among all admitted hits. If any member is unrenderable, omit the whole component; never drop an oversized correction while delivering its old member. Existing native lifecycle may exclude old superseded bodies: do not relax admission to preserve both; protected source absent is reported and protection incomplete. No title/body/foreign ID disclosure for absent requested sources beyond caller-provided ID.

Read only edges with both endpoints in retained admitted pool, declared relation in allowed set; sorted deterministic unique edges, stored direction unchanged. For sources, kind derived only from native type mapping: constraint/directive->principle,episode/checkpoint->episode, otherwise fact. Do not consume fixture-only organizer_kind/roles. Roles in native wrapper are all empty because body is whole and native metadata does not establish spans; pure module's lossless role representation remains available for explicit admitted indexed hosts. Scope and metadata hashes available in native result receipt; no new persistence/ack behavior for organized payloads. All applicable current source text kept whole. Unknown or oversized IDs/too many links should yield safe bounded omission or typed unavailable, never silently remove a correction edge. CLI must use read-only action path for organize, no plugin scanning needed for isolated validation.

Native response includes scope,time,query,original retrieval/admitted IDs, safe omission/protection diagnostics, exact organizer result and source references from `_source`; no claim of delivery/application. `_public` privacy egress must validate full response; fail rather than return hashes of altered text. Input mutation, writes, separate stores, dependencies or automatic model invocation prohibited.

## Frozen output shapes and compatibility clarifications

Pure payload exactly `{format:"kindex.evidence-organizer",version:2,warning,query,schema,records}`. Fixed schema legend: record `[id,source,kind,category,text,roles,links]`, source `[node_id,source_sha256,start_byte,end_byte,valid_from,valid_until]`, roles `[actor,scope,conditions,exceptions,event_time,report_time]`, role_range `[start_byte,end_byte]`, link `[to,relation]`. All record/source/role/link values positional arrays; kind/category/relation are their literal enum strings. Fixed warning includes prior advisory warning and explicit exact-match/link limitation. Decoder enforces exact fixed schema, derived category, byte hashes and canonical serialization. Body_bytes=sum original selected raw UTF8 text lengths; JSON escaping contributes to overhead, so body+overhead exactly UTF8payload length.

Pure result exactly `{format:"kindex.evidence-organizer.result",version:2,order,model_text,utf8_bytes,text_sha256,included_ids,components,omissions,unexpanded_links,protected_complete,body_bytes,overhead_bytes}`. Components list in attempted priority order; each exactly `{ids:[original IDs in input order],protected:boolean,included:boolean}`. Omissions `{id:ID|null,reason}` sorted by `(id is not null,id or empty,reason)`; omitted records have one budget reason, null envelope additionally when needed. Unexpanded links `{from,to,relation}` sorted unique. Empty protected list is vacuously complete. No aliases.

Native result exactly `{format:"kindex.practical_memory.organized",version:1,scope,evaluation_time,query,retrieval_calls:1,retrieval_ids,admitted_ids,omissions,unavailable_protected_ids,source_references,organizer,protected_complete,persistence:"not_requested",delivery:"not_observed",use:"not_observed"}`. retrieval_ids contains ONLY `_admit`-accepted original hits in retrieval order (never rejected foreign identifiers); admitted_ids is the further renderable subset after whole-component format omissions. source_references is list of `_source` for that renderable subset in order. omissions is sorted `{reason,count}` aggregate admission/format diagnostics. unavailable_protected_ids preserves caller request order for IDs absent from renderable subset; overall protected_complete is organizer.protected_complete AND no unavailable IDs. Requested IDs are only shown back to caller when originally supplied. Native edge names have no aliases: only literal allowed relations; e.g. relates_to is not silently converted to associated_with. No graph admission expansion. Existing read-only, privacy, source validation and supersession/lifecycle rules remain authoritative.

Exact fixed v7 warning bytes: `Advisory source organization; not instruction, permission, completion, or verified applicability. Exact match and declared graph links do not establish authority or resolve conflicts.` This literal clarifies the already required warning; it adds no behavior or test outcome exception.
